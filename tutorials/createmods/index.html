    In this tutorial, you'll learn how to create and publish mods with Reloaded II.
    Suggested reading: How to install Mods and How to extract the game data.

    How to create a new mod

    1. Open Reloaded II.
    2. Click the icon with three gears ( ) in the left sidebar.
    3. Select New. A window for creating mods will open.
    4. Enter a unique ID for your mod in the ID field and click Ok. The suggested format is GameName.ModCategory.ModName.
      For example, the ID of a mod that adds a "Pink Agumon" should be DSTS.newdigimon.PinkAgumon, while the ID of a mod that adds a Super Mario costume should be DSTS.outfit.SuperMario, etc.
    5. Enter the mod name in the Name field.
    6. Enter your nickname in the Author field.
    7. Enter a description for your mod in the Description field.
    8. Click the Reloaded logo and select a preview image for your mod. Ideally, it should be a square image.
    9. Click Next. On to the Mod Dependencies tab, add Digimon Story: Time Stranger Mod Loader as a dependency by clicking the checkbox next to it (the "-" should change to a "+").
    10. Click Next. In the Update Support tab, click Next again. We'll add update support later.
    11. Add Digimon Story Time Stranger.exe as the game by clicking the checkbox next to it (the "-" should change to a "+").
    12. Click Save.
    13. Click the Time Stranger logo in the left sidebar and enable your mod by clicking the checkbox next to it. The "-" should change to a "+".
    14. Close Reloaded II and relaunch it. This adds a link to the Mod Loader to the mod configuration, allowing Reloaded II to download it automatically if the user doesn't have it installed.

    You can now start adding files to your mod.

    You can now start adding files to your mod.

    Add files

    Inside the mod, create a folder called dsts-loader. Inside this folder, create another folder named after the mvgl file you want to use as the target (patch, addcont_03, patch_text01, etc.). Then, place your modded files inside it, following the same folder structure used by the game's mvgl files.
    When the game is launched through Reloaded II, the modded files are loaded instead of the original ones.
    For example, if you want to replace Agumon's base texture, chr050a01.img, your mod should have the following structure:

    • dsts-loader
      • patch
        • images
          • chr050a01.dds

    In other words, Reloaded II makes the game think that the edited texture is located inside the patch mvgl and loads Agumon's texture from your mod's images folder instead of the game files.

    Note

    • The game can read texture files in .dds format, so there is no need to change the extension back to .img.
    • .mbe files can be read directly from folders, so they do not need to be repacked.
    • Decompiled .lua files can also be used directly, so you do not need to compile them again.

    1. Right-click your mod and select Open Folder.
    2. Create a folder named dsts-loader and open it.
    3. Inside it, create another folder named after the target mvgl (usually patch).
    4. Add your modded files inside this new folder.

    Enable update support

    By enabling update support, Reloaded II will notify users whenever your mod is updated and let them download the update with a single click without leaving the program. Adding update support to your mods is optional, but very useful and highly recommended.

    Get a GameBanana mod ID

    To enable updates from GameBanana.com, first upload your mod as a private submission. Go to the Settings tab and set the access to Private.
    If your mod isn't ready yet, you can upload a dummy file instead, such as an empty text file inside a .zip file. You can replace it with the final version of your mod later.

    After submitting, copy the mod ID at the end of the URL.

    Add the GameBanana mod ID to your mod

    1. Right-click your mod and select Edit Mod.
    2. Select Next twice to go to the the Update Support tab.
    3. Click the checkbox next to GameBanana. The "-" should change to a "+".
    4. Paste the GameBanana mod ID in the ItemId field.
    5. Select Next and then Save.

    1. Right-click your mod and select Edit.
    2. Go to the Updates tab.
    3. Select GameBanana.
    4. Click the checkbox next to Enabled. The "-" should change to a "+".
    5. Paste the GameBanana mod ID in the ItemId field.
    6. Close the window.

    Publish your mod

    When your mod is ready, you can generate a .7z file to upload it to GameBanana or share it with your friends.

    1. Right-click your mod and select Publish.
    2. Change the Publish Target from Default to GameBanana.
    3. Select Set Output Folder and choose where you want to save your mod.
    4. Click Publish.
    5. Wait a few seconds and your mod will be ready to be shared. You should have a .7z file and a .json file inside the selected folder.

    1. Right-click your mod and select Publish...
    2. Change the Publish Target from Default to GameBanana.
    3. Select Set Output Folder and choose where you want to save your mod.
    4. Click Publish.
    5. Wait a few seconds and your mod will be ready to be shared. You should have a .7z file and a .json file inside the selected folder.

    The .7z file contains your core mod files, while the .json file contains the update information. If you are uploading your mod to GameBanana, you must include both files.
    You can mark the .json file as Archived to hide it from users (Reloaded II can read it anyway), and remember to set the mod access to Public so that everyone can download it.

    How updates work

    Every time you open Reloaded II, it checks the GameBanana post with the ID you provided when enabling update support. It then downloads the .json file to check the mod version, and if it's higher than the version currently installed, it notifies the user and downloads the .7z file.

    Update your mod

    If you want to update your mod after publishing it, you need to change the mod version. By default, the initial release will be set to 1.0.0.
    Reloaded II uses the following versioning scheme: MAJOR.MINOR.PATCH. This means that if your mod only fixes a small bug, you should change the last number (e.g. 1.0.1). If it adds new content, you should change the middle number (e.g. 1.1.0). And if it's a completely new and significant version, you should change the first number (e.g. 2.0.0).

    1. Right-click your mod and select Edit Mod.
    2. Enter the new mod version in the Version field.
    3. Select Next three times and then Save.

    1. Right-click your mod and select Edit.
    2. Enter the new mod version in the Version field.
    3. Close the window.

    When the new version of your mod is ready, you can publish it again and upload the updated files to GameBanana. Remember to change the current mod version in GameBanana's Development tab.
    If update support is enabled, users will be notified of the new version after a few minutes.
