    How to extract the game data

    Containers

    All the game assets are stored in the "gamedata" folder. The default path is:
    C:\Program Files (x86)\Steam\steamapps\common\Digimon Story Time Stranger\gamedata

    • .cpk files contain sound and videos .
    • .mvgl files contain everything else: 3D models, databases, textures, etc. .

    They are organized in the following way:

    • Files with the app prefix contain all the unpatched base game assets.
    • Files with the patch prefix contain all the assets added through patches.
    • Files with the addcont prefix contain DLC data.
    DLC IDs

    addcont_01 = episode pack 1
    addcont_02 = episode pack 2
    addcont_03 = episode pack 3
    addcont_05 = Golden Moai farm item
    addcont_06 = Special Agumon and Gabumon (Early Unlock)
    addcont_07 = Costume Public Safety Suit & Special Supplies Set
    addcont_08 = Cyber Sleuth BGM Pack.
    addcont_09 = Anime Song Pack.
    addcont_10 = Outer Dungeons The Halls of EXP, Gold, Materials
    addcont_12 = Cyber Sleuth costume
    addcont_13 = Swimwear costume
    addcont_14 = Chosen Children costume
    addcont_15 = Digimon costume
    addcont_17 = preorder bonus (Black Agumon and Black Gabumon)

    • Files with the _text## sufix contain text data for the different languages (Digimon names, skill names, UI, dialog, etc.).
    Language IDs

    text00 = Japanese
    text01 = English
    text02 = French
    text03 = Spanish (Eu)
    text04 = German
    text05 = Italian
    text07 = Portuguese (LatAm)
    text09 = Korean
    text10 = Traditional Chinese
    text11 = Simplified Chinese
    text30 = Spanish (LatAm)

    Examples

    • addcont_17_text00.dx11.mvgl contains Japanese text for the preorder bonus DLC.
    • patch.dx11.cpk contains sound files from patches.
    • app_text01.dx11.mvgl contains English text from the base game.

    Tools

    There are a variety of tools that can be used to extract the game's data:

    • To extract audio from .cpk files, use CriFsLib (Read how to extract audio).
    • For general file extraction:
    Tool Extracts mvgl Unpacks mbe Decompiles lua
    Digimon Time Stranger ToolKit
    MVLibrary
    MVGLTools

    Extract the game data

    • Download Digimon Time Stranger ToolKit from Github (Code → Download ZIP).

    • Move the zip file to the location where you want to install it, such as a "DSTS Toolkit" folder on your desktop.
    • Extract the contents of the zip into that folder, then run mvgl_tools_gui.exe.
    • Digimon Time Stranger ToolKit's MVGL Tools menu should now open.
    • Change the "operation" to unpack-mvgl.
    • Select the source file (the mvgl file you want to extract) and the target folder (where the extracted content will be saved), then click Execute to start the extraction.
    • Wait until the "operation completed successfully" message appears.

    • Download the latest version of MVLibrary from GitHub (MVLibraryNET.GUI-windows.zip).
    • Move the zip file to the location where you want to install it, such as a "MVLibrary" folder on your desktop.
    • Extract the contents of the zip into that folder, then run MVLibraryNET.GUI.exe.
    • MVLibrary should now open.
    • Drag and drop a .mvgl file from the "gamedata" folder into MVLibrary.

    • Select the files you want to extract → right click → extract
    • Choose a folder to save the extract files.

    Tip

    To select multiple files, use the Ctrl or Shift keys.

    MVGLTools is a command-line tool, so it can be a little bit confusing.

    1. Download the latest version of MVGLTools from GitHub (MVGLTools-v[version]-win64.zip).
    2. Move the zip file to the location where you want to install it, such as a "MVGLTools" folder on your desktop.
    3. Extract the contents of the zip into that folder.
    4. Click the address bar at the top of the window.
    5. Type cmd and press enter.
    6. A black window called Command Prompt will open.
    7. Copy and paste the following command:
      MVGLToolsCLI.exe --game=dsts --mode=unpack-mvgl "C:\Program Files (x86)\Steam\steamapps\common\Digimon Story Time Stranger\gamedata\app_0.dx11.mvgl" "out"
    8. Then press Enter. Wait until the Command Prompt stops processing.
    9. When it finishes, a new folder named out will appear inside the MVGLTools folder with the extracted files.

    To extract a different file, change the filename or path from step 7.

    Tip

    I recommend extracting the app_0 MVGLs first, then extracting the patch MVGLs so the patched files replace the outdated ones.

    Unpack MBE files

    .mbe files contain .csv data tables with various parameteres, including Digimon stats, evolution conditions, skill effects, item information, and more.
    They are located in the data and text folders inside the .mvgl files.

    • Extract the .mbe files from the game data.
    • Open Digimon Time Stranger ToolKit. Change the "operation" to unpack-mbe-dir to extract all the .mbe files inside a folder, or to unpack-mbe to extract a single file.
    • Select the source folder/file and the target folder and click the Execute button to start the extraction.

    • Wait until the "operation completed successfully" message appears.

    1. Extract the .mbe files from the game data.
    2. Open the MVGLTools folder.
    3. Create a new folder named mbe inside it, then place all of your .mbe files in that folder.
    4. In the MVGLTools folder, click the address bar at the top of the window.
    5. Type cmd and press enter. This will open a Command Prompt window.
    6. Copy and paste the following command:
      MVGLToolsCLI.exe --game=dsts --mode=unpack-mbe-dir mbe mbe/out
    7. Then press Enter. Wait until the Command Prompt stops processing.
    8. When it finishes, a new folder named out will appear inside the mbe folder with the extracted CSV files.

    Edit CSV files

    To edit CSV data tables, you can use:

    • Any text editor, like Windows Notepad, or Notepad++ which has some handy CSV plugins.

    • For files with a lot of columns, use LibreOffice Calc. Make sure the character set is Unicode (UTF-8) when opening the files.

    If decimal numbers use commas (like 0,5 instead of 0.5), change your region or the data may not work correctly in-game. Go to Tools → Options → Languages and Locales → General, then change the locale setting to "English (USA)".
    As an alternative to LibreOffice, you can use Modern CSV, though some features are paywalled.

    Warning

    Do NOT use Microsoft Excel to open CSV files. It changes the column format and causes a lot of problems.

    Info

    • Digimon Story: Time Stranger Mod Loader lets the game read unpacked .csv files directly from folders, so you don't need to pack them again. Just place your edited CSV files in a folder with the same name as the MBE file and add it in your mod.

    Example

    char_info.mbe
    └─ 000_char_info.csv

    • The .ap prefix appends the content of the .csv file to the original file instead of replacing it.

    Example

    000_char_info.csv → replaces the original file.
    000_char_info.ap.csv → appends its entries to the original file.

    If you want to add a new entry, use the .ap prefix. If you want to modify an existing entry, don't use the .ap prefix.

    Extract sound and videos

    • Open CriFsLib.
    • Drag and drop the desired .cpk file into the program.
    • Right click on the desired media file → extract selected.
      To select multiple files, use the Ctrl or Shift keys.
    File types
    • BGM prefix: music .
    • en/voice prefix: English voices and dialog .
    • ja/voice prefix: Japanese voices and dialg .
    • SE prefix: sound effects (UI, skills, etc) .
    • .usm filetype: movies .

    Play and convert sound files

    To play the extracted sound files, use Foobar2000 and install vgmstream decoder (file → preferences → components → install).
    To convert custom sound files into .hca for mods, use Yona.

    Decompile LUA

    .lua files (located in the lua folder) contain scripts. They control NPC interactions, teleports, cutscenes, and so on.
    Since the game's Lua files are precompiled as Lua 5.2 bytecode, they must be decompiled before they can be edited.

    • Extract the LUA files from the MVGLs.
    • Download and install Java.
    • Run lua_decompiler_gui.exe, located in the Digimon Time Stranger ToolKit folder.
    • Select the folder containing the extracted LUA files ("Source Folder"), then choose where you want the decompiled files to be saved ("Output Folder").
    • Click "start decompilation" and wait for the process to finish.
    • You can now open and edit the Lua files in any text editor.

    Info

    The game can read decompiled .lua files, so you don't need to compile them again.

    3D models

    3D models consist of three different file types:
    .geom files contain geometry, bones and materials.
    .nlst files contain node lists (bone hierarchy, etc.).
    .anim files contain animations.

    To open these files, you must install Blender and one of the following add-ons:

    Add-on Imports mesh Imports animations Exports mesh Exports animations Blender version
    Zeak's 4.5
    Romsstar's 4.5
    Nymic_Razor's 4.5
    Senator John's 5.1
    How to install add-ons

    Note

    In Blender 4.5, instead of an Install button, you'll see a arrow. Click it and select Install from Disk.

    Known bugs and limitations
    • Some add-ons are not compatible with each other. Don't install all of them at the same time, or you may encounter errors.
    • Skill effects, particles, lights, texture animations and object collisions can't be edited yet.
    • Time Stranger models contain many unnecessary vertices, which significantly increase the file size. To remove them, enter edit mode, select all and go to Mesh → Clean Up → Delete loose.
    • Some meshes become invisible if they only have 1 weight. Assign a random bone (preferably mvglDummy0000) with a weight of 0.001 to fix it.
    • Edited/custom digimon models may have thicker outlines (workaround).
    • Custom player models can't use train terminals.
    • When using a custom player model, the Palmon you call to travel between floating islands in the Gear Forest will be invisible during the cutscene.
    • If your model has weird shadows, it's likely a weight normalization problem. The sum of all weights must be exactly "1". To fix it, enter weight paint mode and go to weights → normalize all.

    Textures

    Textures are in DDS format but use the .img file extension. Simply rename the files to .dds, and you'll be able to edit them with any image editing software (Paint.net, Photopea, etc.).
    For more information, check the texture documentation.
