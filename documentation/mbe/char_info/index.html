    char_info.mbe

    This MBE controls voice lines and profile pictures.

    • string2 0: character key (a unique internal name for the Digimon). Must match the character key used in digimon_status.mbe. Should be the Digimon name in uppercase with the char_ prefix (for example, char_AGUMON).
    • string2 3: unknown. Must match the model filename used in digimon_status.mbe.

    Profile picture

    • string2 4: profile picture ID.
      The profile picture filename must be ui_chara_icon_#.dds, where # is the picture ID. For example, Agumon's profile picture is named ui_chara_icon_1001, so the value in this field should be 1001.
      This ID also determines whether two or more Digimon are considered the same species in battle, in which case they are assigned the suffixes "A", "B", "C" and so on.

    Voices

    • string2 8: voice line set ID. It's the voice used by playable Digimon in battle.

    Info

    The voice lines for Special Skills are hardcoded, and don't change even if you change the voice set.

    • string2 10: NPC voice line set ID. Voice line used when the Digimon is a wild enemy or an NPC.

    • string2 12: Guttural voice set ID. Voice used by NPCs and enemies that produce grunts and shrieks instead of speaking. Used by only a few bosses, although it can be assigned to any Digimon.
