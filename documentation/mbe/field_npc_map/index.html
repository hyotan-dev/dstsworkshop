    Field_npc_#.mbe

    Controls basic NPC parameters. "#" is the ID of the map. For example, Field_npc_t3001.mbe controls all the NPCs in the In-Between Theater (map t3001).

    Some map IDs

    t3001 = In-between Theater
    d0506 = Coliseum lobby
    d0552 = Coliseum Arena
    d0306 = Zeppelin interior
    d0204 = Central Town Tabern
    t0201 = Akihabara
    t0403 = Inori's House
    d0503 = Mines

    001_field_npc.csv

    • int32 0: NPC ID. Must be map ID + unique NPC ID. For example, 3001501 is the Bartender in the In-Between Theater (3001 = map ID, 501 = NPC ID).
    • int32 1: visibility. -1 = always visible.
    • string2 2: Internal NPC name. Must be unique per map.
    • string2 3: interaction ID. Must be unique per map.
    • string2 5: model name. Can be the 3D model file name without extension (i.e. "chr050" for Agumon) or an entry in union_model.mbe, which controls hairstyles and other aspects.
    • int32 6: rendering. 0 = 3d model. 1 = dot sprite.
    • string2 10: idle animation name.
    • string2 14: face animation name. F01 = normal (idle); F02 = closed; F03 = angry.
    • int32 15: closed eye type: 0 = happy; 2 = asleep.
    • float 17: Y position.
    • float 18: Z position.
    • float 19: X position.
    • float 20: Z rotation. 0 = facing front; 90 = facing left; -90 = facing right.
    • float 21: X rotation. 0 = straight; 45 = leaning forward; -45 = leaning back.
    • float 22: Y rotation. 0 = straight; 45 = inclined to the right; -45 = inclined to the left.
    • float 25: interaction range. The distance at which you can interact with the NPC.
    • float 27: interaction angle. 360 = can be interacted from any angle; 90 = can only be interacted with from the front.
    • float 29: Interaction position? If an NPC is floating in the air, and you replace 1 with 2, you can interact with it.
    • int32 30: Icon ID.
