    item.mbe

    This MBE controls item settings. It contains two CSVs, one for basic item features and another one for equipment effects.

    000_item_parameter.csv

    Basic parameters

    • int32 0: unique item ID.
    • int32 4: item name ID (same as the item ID). Set the name in text/item_name.mbe.
    • int32 5: item description ID. 0 = automatic description. Item ID = unique description (set in text/item_explanation.mbe).
    • int32 6: item category.
    Categories

    0 = recovery.
    1 = enhancements.
    2 = special.
    3 = skill discs (if an item belongs to this category, it must have an entry in text/skill_ruby.mbe or the game crashes).
    4 = equipment (if an item belongs to this category, it must have an entry in 001_equip_parameter.csv).
    5 = materials.
    6 = farm.
    7 = costumes/clothes.
    8 = valuables.
    9 = cards.

    • int32 7: icon ID. Must be a number from 0 to 99. To know the ID of an icon, check the texture filename ("ui_icon_item_0##.img", the last two digits are the ID).
    • int32 8: item sorting ID. A unique number used for sorting. You can use the same number as the item ID in int32 0.

    Price

    • int32 9: buy price.
    • int32 10: sell price.

    Usability

    • bol 11: can be used in battle? true = yes. false = no.
    • bol 12: can be used in the overworld? true = yes. false = no.

    Effects

    • int32 13: skill ID triggered by the item (from battle_skill.mbe/000_battle_skill_list.csv). If this column is used, "int32 15" must be 0 and "int32 16" must be -1.
    • int32 15 and int32 16: overworld effect. -1 in both columns if it can't be used in the overworld. Otherwise, use any of the effects from the list below. Int32 15 contains the effect ID, and int32 16 contains the value related to that effect.
    Effect list
    int32 15 (effect) int32 16 (value)
    0 = Uses a skill If "int32 15" is 0, "int32 16" must be -1, and the skill ID set in "int32 13".
    3 = Experience Amount of experienge gained.
    4 = Bond Amount of bond/friendship gained (multiplied by 100).
    9 = Change personality Personality ID (0 to 16).
    10 = Move personality (horizontal) Moves personality between "Heart" and "Understanding".
    11 = Move personality (vertical) Moves personality between "Affection" and "Companionship".
    12 = Talent Amount of Talent (level cap) gained.
    13 = Max HP Amount of HP gained.
    14 = Max SP Amount of SP gained.
    15 = ATK Amount of ATK gained.
    16 = DEF Amount of DEF gained.
    17 = INT Amount of INT gained.
    18 = SPI Amount of SPI gained.
    19 = SPD Amount of SPD gained.
    20 = Anomaly points Amount of anomaly points gained.

    Example

    If you want to create an item that increases SPI by 500, "int32 15" must be 18 and "int32 16" must be 500.

    • int32 17 and int32 18: second overworld effect. Same functionality and values as int32 15 and 16. Combining out-of-battle effects is not fully supported and some text can look broken.

    Scripts

    • string2 19: lua function name. Used to run lua scripts.

    Costumes

    • int32 26: costume ID. If you have this item in your bag, it unlocks a costume/outfit for the protagonist.

    Digifarm

    • string2 27: image filename used as thumbnail in the Digifarm (without file extension).

    001_equip_parameter.csv

    If an item is categorized as equipment in the previous CSV (int32 6 → 4), it also needs an entry in this csv to get an effect.

    • int32 0: item ID. Same item ID used in the first column of 000_item_parameter.csv.

    Stat boost

    • int32 2: amount of max HP increased.
    • int32 3: amount of max SP increased.
    • int32 4: amount of ATK increased.
    • int32 5: amount of DEF increased.
    • int32 6: amount of INT increased.
    • int32 7: amount of SPI increased.
    • int32 8: amount of SPD increased.
    • int32 9: amount of ACU increased.
    • int32 10: amount of EVA increased.
    • int32 11: amount of CRT increased.

    Elemental resistances

    • int32 12: Boosts Null resistance? 0 = no; 1 = yes.
    • int32 13: Boosts Fire resistance? 0 = no; 1 = yes.
    • int32 14: Boosts Ice resistance? 0 = no; 1 = yes.
    • int32 15: Boosts Plant resistance? 0 = no; 1 = yes.
    • int32 16: Boosts Water resistance? 0 = no; 1 = yes.
    • int32 17: Boosts Electricity resistance? 0 = no; 1 = yes.
    • int32 18: Boosts Steel resistance? 0 = no; 1 = yes.
    • int32 19: Boosts Wind resistance? 0 = no; 1 = yes.
    • int32 20: Boosts Earth resistance? 0 = no; 1 = yes.
    • int32 21: Boosts Light resistance? 0 = no; 1 = yes.
    • int32 22: Boosts Dark resistance? 0 = no; 1 = yes.

    Status effect nullification

    • int32 35: ID of the status effect nullified by the equipment.
    Status effect list

    3 = poison.
    5 = confusion.
    6 = paralysis.
    7 = sleep.
    8 = crystallization.
    9 = bug/reversion.
    10 = instant death.
    12 = status abnormalities.
    13 = stat debuffs.
    29 = poison and deadly poison.
    30 = confusion and chaos.
    31 = paralysis and immobilization.
    32 = sleep and deep slumber.

    Special effects

    • int32 36, int32 37 and int32 38: special effect triggered by the attachment.
    Special effect IDs
    int32 36 int32 37 int32 38
    10 = "Boosts effects of HP recovery by X% when in battle" Amount of HP recovery increased 0
    16 = "Attacks apply debuff to enemies" (debuff ID goes in int32 40) 0 0
    17 = "Attacks deal magic damage instead of physical" 0 0
    21 = "Consumes X% more SP to deal Y% more damage" Amount of extra SP consumed Damage increase percentage
    23 = "Restores SP equal to X% of physical damage taken" Amount of SP restored 0
    24 = "Restores SP equal to X% of magic damage taken" Amount of SP restored 0
    25 = "Nullifies any damage below X%" Damage percentage 0
    26 = "Boosts CRT damage by X%" Increased damage percentage 0
    33 = "Reduces damage received from [attribute] Digimon by X%" Attribute ID Damage reduction percentage (use negative numbers, or you will receive more damage instead)
    34 = "Applies buff/debuff to user at the beginning of a battle" ( Debuff ID goes in int32 40) 0 0

    Apply buffs and debuffs

    • int32 40: adds effects from battle_skill.mbe / 002_buff_set.csv to enemies (if "int32 36" is 16) or to the Digimon the item is attached to (if "int32 36" is 34).
