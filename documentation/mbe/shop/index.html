    shop.mbe

    This MBE controls shop parameters and items available in each shop.

    Add shops to NPCs

    Shops are added to NPCs through lua script. Open the corresponding NPC lua file and add a new script for that map ID under the OnCheckNPC function: 

    elseif talk_id == INTERACTION then
  START_TALK_ACTION_AND_ZOOM(npc_name, true, false)
  CommonShopStart_NoZoomCam(npc_name, SHOPID, "ANIMATION1", "ANIMATION2", "ANIMATION3", "ANIMATION4")
  END_TALK_ACTION_AND_ZOOM(npc_name, true, false)
  Prcs_t30_InvisibleFollower()
    - INTERACTION is the NPC interaction ID from field_npc_map.mbe (string2 3).
    - SHOPID is the shop ID from 000_shop_parameter.csv.
    - ANIMATION1 is the name of the animation played by the NPC when you interact with it.
    - ANIMATION2 is the name of the animation played by the NPC when you buy an item.
    - ANIMATION3 is the name of the animation played by the NPC when you sell an item.
    - ANIMATION4 is the name of the idle animation used by the NPC (usually bn01).

    000_shop_parameter.csv

    Basic parameters for each shop.

    • int32 0: unique shop ID.
    • int32 2: shop content. Same ID as the first column. Using the ID of a different shop displays that shop's contents instead.
    • int32 4: unknown. Always 0.
    • int32 8 to int32 16: unknown. Changing the values doesn't seem to have any visible effect.
    Add text to a shop

    To add text to a shop, it must have four entries in patch_text##/message/field_text.mbe, one for each interaction (greeting, farewell, buy and sell).

    • string2 0: interaction ID:
      g_shop###_0010_0010 = greeting message .
      g_shop###_0020_0010 = farewell message .
      g_shop###_0030_0010 = message displayed when the player buys an item .
      g_shop###_0040_0010 = message displayed when the player sells an item .
      (### is the shop ID. It must be at least 3 digits long. If the shop ID has fewer than 3 digits, add leading zeros. For example: 96 → 096.)
    • string 1 character key. Used for the name of the NPC.
    • string 2: message. Maximum 2 lines (any additional lines will appear below the text box instead of inside it).
    • string 3: unknown. Always empty.

    001_shop_lineup.csv

    Specifies which items are sold in each shop.

    • int32 0: unique lineup ID.
    • int32 1: shop ID.
