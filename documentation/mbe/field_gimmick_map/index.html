    Field_gimmick_#.mbe

    Controls basic gimmick parameters. Gimmicks are world objects, similar to NPCs, but with some differences: they can be destroyed, the collision is a box instead of a sphere, and you can walk on them. Useful for things like bridges, platforms or custom small areas.
    # represents the map name. For example, Field_gimmick_t3001.mbe controls all the objects in the In-Between Theater (map t3001).

    001_field_gimmick.csv

    • int32 0: object ID. Must be the map ID followed by a unique object ID.
    • int32 2: visibility flags. -1 = always visible.
    • string2 3: Internal object name. Must be unique per map.
    • string2 6: model name. 3D model file name without extension (i.e. "chr050" for Agumon).
    • string2 12: idle animation name. Empty: none.
    • float 16: Y position. To check your current coordinates, use the coordinate finder.
    • float 17: Z position.
    • float 18: X position.
    • float 19: Z rotation. 0 = facing front; 90 = facing left; -90 = facing right.
    • float 20: X rotation. 0 = straight; 45 = leaning forward; -45 = leaning back.
    • float 21: Y rotation. 0 = straight; 45 = inclined to the right; -45 = inclined to the left.
    • float 25: collision Z.
    • float 26: collision Y.
    • float 27: collision X.
    • int32 35: Icon ID.
