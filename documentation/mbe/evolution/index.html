    evolution.mbe

    This MBE controls evolution lines and requirements.

    • int32 0: Digimon ID.
    • int32 2: agent level.
    • int32 3: minimum Digimon level.
    • int32 4: HP.
    • int32 5: SP.

    001_evolution_to.csv

    • int32 0: unique ID for each evolution.
    • int32 1: ID of the Digimon that will evolve.
    • int32 3: ID of the Digimon it evolves into.
    • int32 5: 0 = normal evolution. 2 = form change.
    • int32 6 to 10: DLC requirement flags. only used by Parallelmon (flag 27500) and the Special Agumon and Gabumon from the Ultimate Edition early unlock (flag 29905).

    Info

    To calculate De-Digivolution, the game simply reads the evolution entries in reverse.
    However, form changes work differently: both Digimon must have a corresponding evolution entry pointing to the other.

    Examples

    • For the evolution from Agumon to Greymon, a single evolution entry is sufficient. The game automatically recognizes that Greymon can De-Digivolve into Agumon.
    • For the form change between Omnimon and Omnimon Zwart, you need one entry where Omnimon evolves into Omnimon Zwart, and another where Omnimon Zwart evolves into Omnimon.

    002_chronodevolution.csv

    SPOILER ALERT: endgame content

    This CSV defines the De-Digivolved forms that your Digimon turns into when Chronomon uses Chrono Devolution during the final boss fight.

    Column Description
    int32 0 Digimon ID
    int32 2 Baby form ID
    int32 3 Rookie form ID
    int32 4 Champion form ID
    int32 5 Ultimate form ID
    int32 6 Mega form ID
    int32 7 Mega+ form ID

    Unused columns (stages beyond the Digimon's current stage) must be filled with -1.

    Example

    Since Agumon is a Rookie, the Champion, Ultimate, Mega, and Mega+ columns must be set to -1.
