    model_setting.mbe

    This mbe contains a single CSV file. It controls various visual settings for any model, both playable and not playable. Most of the fields are still under investigation.

    000_model_setting.csv

    • string2 0: model name (without file extension).
    • float 8: follower collision. An invisible sphere that makes your Digimon bump into each other while following you in the overworld.
    • float 10: NPC collision. An invisible sphere around NPCs that blocks movement. 0 = no colission (players can pass through NPCs).
    • float 22: overworld fade out distance. Controls how close the camera can get before the model fades out in the overworld. 0 = the model never fades out.
    • float 26: camera zoom out while riding.
      0 = no camera change (used by Terriermon Assistant). 5 = Default (the camera zooms out slightly, used by the rest of the models).
    • string 2 27: second idle animation. Extra animation that occasionally interrupts the normal idle loop. Default: fe02.
    • string 2 29: third idle animation. Empty by default, but any Digimon can use it.
    • string 2 31: fourth idle animation. Empty by default, but any Digimon can use it.
    • Float 33: walking speed while following you in the overworld.

    Battle

    • float 38: Digimon distance from other party members in battle.
    • float_39: player distance from Digimon in battle.
    • int 40 player angle from Digimon in battle (in degrees; 0 = player is in front of the Digimon; 180 = player is behind the Digimon).
    • float 41 fade out distance in battle. Controls how close the camera can get before the model fades out in battle. 0 = the model never fades out.
    • float 43 skill camera distance in battle. Distance of the camera when choosing skills.
    • float_47: shield and buff/debuff size in battle.

    Model size

    • float 56: general scale. Controls the size of the model in all scenarios. It's the size used as the base for the other size columns.
    • float 57: Digifarm scale. Size of the Digimon when it's deposited in the Digifarm.
    • float 58: menu scale. Size of the Digimon in the summary screen and the Field Guide.
    • float 59: map scale. Size of the Digimon when it's following you in the overworld.
    • float 60: battle scale. size of the Digimon in combat.
    • float 61: special skill and victory scale. Sized of the Digimon during the bv# (victory) abd bs# (special skill) animations.
    • float 62: NPC scale. Sized used when the Digimon is added to the overworld as an NPC.
    • float 63: enemy scale in the overworld. Size of the Digimon when it's an enemy in the map outside of battle.

    Attack sound

    • int32 66: ID of the audio track played when the Digimon uses the Attack command in battle.

    Riding

    • Float 71: controls if the Digimon is rideable or not.
      0 = not rideable. 1 = rideable (flies). 2 = rideable (walks/runs/floats).
      If the Digimon is rideable, it must have an entry in field_anime.mbe or the game will crash.
