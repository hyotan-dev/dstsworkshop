    battle_enemy.mbe

    Controls enemy parameters in battle. Includes six CSV files, but to add new enemies we will only use: 000_enemy_parameter.csv, 001_encount_group.csv and 004_battle_enemy_ai.csv.

    Abstract

    A wild enemy needs:
    1. An overworld spawn in field_battle_[map].mbe.
    2. A battle group in battle_enemy.mbe/001_encount_group.csv.
    3. An enemy entry in battle_enemy.mbe/000_enemy_parameter.csv.
    4. An entry in battle_enemy.mbe/004_battle_enemy_ai.csv to determine which skills it can use. 

    flowchart TD
A[field_battle_#.mbe] --> |Checks encounter group| B
B[battle_enemy.mbe] --> C[001_encount_group.csv]
C[001_encount_group.csv] --> |Checks enemy data| D
D[000_enemy_parameter.csv] --> |Determines the enemy's overworld model| A
D[000_enemy_parameter.csv] --> |Checks which skills it can use| E
E[004_battle_enemy_ai.csv]

    000_enemy_parameter.csv

    • int32 0 = unique enemy ID. This value must be the Digimon's ID from digimon_status.mbe, followed by 01. For example Gabumon's ID is 151, so its enemy ID should be 15101.

    Info

    To create multiple variants of the same Digimon with different parameters for different battles, replace the trailing 01 with 02, 03, and so on. For example, 15102 and 15103 would represent additional variants of Gabumon.

    • int32 2 = base Digimon ID from digimon_status.mbe.
    • int32 5 = Same number used in column int32 0.

    Enemy battle stats

    (Stats used in battle. Overrides base stats from digimon_status.mbe)

    • int32 17 = base HP (at level 1).
    • int32 18 = base SP (at level 1).
    • int32 19 = base ATK (at level 1).
    • int32 20 = base DEF (at level 1).
    • int32 21 = base INT (at level 1).
    • int32 22 = base SPI (at level 1).
    • int32 23 = base SPD (at level 1).

    Buff Resistance

    • int32 32 = ID from battle_buff.mbe/001_buff_resist_set.csv.
      0 = no buff resistances.

    Experience and money

    • int32 33: base experience gained when the enemy is defeated (at level 1).
    • int32 34: additional experience gained per enemy level.
    • int32 35: base money gained when the enemy is defeated (at level 1).
    • int32 36: additional money gained per enemy level.
    Example

    The formula is Base money gain + (extra money gain x {current level - 1}).
    Agumon gives 40 yen at level 1 and grants an additional 4 yen per level.
    Therefore, at level 10, it grants 76 yen in total (40 + [4 × {10 - 1}] = 76).

    Suggested money and experience gains
    Stage Base EXP Additional EXP Base money Additional money
    In-training I 4 2 10 1
    In-training II 1 1 10 1
    Rokie 24 4 40 4
    Champion 84 6 80 8
    Ultimate 264 8 160 16
    Mega 664 10 320 32
    Mega + 1364 12 350 35

    Item drops

    • int32 37 = first item dropped when the enemy is defeated (0 = none).
    • int32 39 = first item drop rate (0 to 100).
    • int32 40 = second item dropped when the enemy is defeated (0 = none).
    • int32 42 = second item drop rate (0 to 100).

    Scan rate

    • int32 43 = scan percentage added when the enemy is defeated (0 to 200).
    Suggested scan rates
    Stage Scan rate
    In-training I 100
    In-training II 100
    Rookie 20
    Champion 15
    Ultimate 10
    Mega 5
    Mega+ 5

    Danger

    Only Digimon with IDs below 32768 in digimon_status.mbe should be scanned. Otherwise, they will crash the game in the Convert screen. This happens because the game stores scan values as int16 instead of int32, causing IDs above 32767 to overflow.

    001_encount_group.csv

    Controls the groups of enemies that spawn during a battle. The enemy in the first slot (int32 2) determines the model used by the wild spawn field_battle_map.csv. Even if the battle only has one enemy, it must have an entry in this CSV.

    • int32 0 = unique encounter group ID.
    • int32 2 = first enemy ID (from 000_enemy_parameter.csv).

    Danger

    The model of the enemy in the first slot must always start with chr or the game will crash.

    • int32 6 = first enemy spawn chance (for the first enemy, always 100 or game crashes).
    • int32 8 = first enemy level.
    • int32 9 = first enemy level in Mega difficulty.
    • int32 10 = first enemy level in Mega + difficulty.
    • int32 14 = second enemy ID.
    • int32 18 = second enemy spawn chance (0 to 100).
    • int32 20 = second enemy level.
    • int32 21 = second enemy level in Mega difficulty.
    • int32 22 = second enemy level Mega + difficulty.
    • int32 26 = third enemy ID.
    • int32 30 = third enemy spawn chance (0 to 100).
    • int32 32 = third enemy level.
    • int32 33 = third enemy level in Mega difficulty.
    • int32 34 = third enemy level Mega + difficulty.
    • int32 38 to int32 74 = fourth to sixth enemy. Unused. Normal battles only allow 3 enemies per battle.
    • string2 75 = lua script used during this battle.
      (empty) = normal battle, no special scripts, no Surprise Encounters.
      battle_00000000 = normal battle with 1% chance of getting a Surprise Encounter.
    Surprise Encounter odds
    Digimon Probability
    PlatinumNumemon 0.35%
    GoldNumemon 0.30%
    BlackKingNumemon 0.20%
    Digitamamon 0.15%
    • int32 80 = battle formation. Determines camera setup and the positioning of enemies during battle.
      803 = standard battle formation used by most encounters.
      201 = enemies are positioned slightly closer to the player's party.
      143 = enemies are positioned slightly farther from the player's party.
      121 = enemies are positioned very close to the player's party.
      61 = enemies are positioned very far from the player's party.

    004_battle_enemy_ai.csv

    Determines which skills each enemy can use in battle, either Special Skills or Attachment Skills. Enemies without an entry in this CSV will only use the Attack command. Overrides special skills from digimon_status.mbe.

    • int32 0: unique AI ID. Must be the enemy ID from 000_enemy_parameter.csv, followed by 00. For example Gabumon's enemy ID is 15101, so its AI ID should be 1510100.
    • int32 12: ID of the first skill used by the enemy.
    • int32 14: chance of using the previous skill (0 to 100).
    • int32 18: ID of the second skill used by the enemy.
    • int32 20: chance of using the previous skill (0 to 100).
    • int32 24: ID of the third skill used by the enemy.
    • int32 26: chance of using the previous skill (0 to 100).
    • int32 30: ID of the fourth skill used by the enemy.
    • int32 32: chance of using the previous skill (0 to 100).
    • int32 66: attack skill ID. Must be 10011.
    • int32 68: chance of using the default attack.
