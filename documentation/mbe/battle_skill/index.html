    battle_skill.mbe

    This MBE manages skills, including both Special Skills and Attachment Skills, as well as item effect skills.

    000_battle_skill_list.csv

    • int32 0: unique skill ID.
    • int32 4: skill name ID (same as the skill ID). Set the name in text/skill_name.mbe.
    • int32 5: skill description:
      0 = automatic description.
      Skill ID = unique description (set in text/skill_explanation.mbe).
      -1 = no description.

    Visual effects

    • int32 9: hit effect (overworld). Visual effect displayed when using DigiAttack against an object or a wild Digimon.
    Overworld hit effect list

    30311 = Null
    30011 = Fire
    30101 = Ice
    30071 = Plant
    30041 = Water
    30131 = Electricity
    30221 = Steel
    30191 = Wind
    30161 = Earth
    30251 = Light
    30281 = Dark

    (From battle_effect.mbe / 000_battle_effect_list.csv)

    • int32 10: Animation ID.
    Animation IDs

    1 = physical attack (ba01)
    2 = magic attack (ba02)
    3 = Special Skill 1 (bs01)
    4 = Special Skill 2 (bs02)
    5 = Special Skill 3 (bs03)
    6 = Special Skill 4 (bs04)
    15 = Guard 1 (bg01)
    17 = Idle 2 (fe02)
    18 = Guard 2 (bg02)
    19 = Hit (bd01)

    • int32 11: Hit zoom. Camera distance enemy is hit. 1 = default.
    • int32 12: Main effect ID, from battle_effect.mbe / 000_battle_effect_list.csv. Played when the Digimon uses the skill.
    • int32 16: hit effect (combat). Visual effect when target is hit.
    Battle hit effect list

    12002 = Null
    12003 = Fire
    12004 = Ice
    12005 = Plant
    12006 = Water
    12007 = Electricity
    12008 = Steel
    12009 = Wind
    12010 = Earth
    12011 = Light
    12012 = Dark

    (From battle_effect.mbe / 000_battle_effect_list.csv)

    Category

    • int32 20: skill category:
      0 = Special Skill
      1 = Attachment Skill
      2 = Item skill (effect used by HP Capsules and similar items, does not consume a turn)

    Damage

    • int32 22: damage type:
      0 = None
      1 = Physical
      2 = Magic
      4 = Fixed Damage
      5 = Fixed Damage (%)
      6 = Buff
      8 = Healing
      9 = Fixed Healing
      11 = Major Damage

    • int32 23: damage power (or healing power if the skill is a healing skill).

    • int32 26: extra damage condition.
    Damage condition IDs

    0 = none
    1 = The lower the user's HP, the higher the damage
    2 = The lower all allies' HP, the greater the damage
    3 = The lower the user's HP, the lower the damage
    4 = The lower all allies' HP, the lower the damage
    5 = The lower the user's SP, the greater the damage
    6 = The lower all allies' SP, the greater the damage
    7 = The lower the user's SP, the lower the damage
    8 = The lower all allies' SP, the lower the damage
    9 = The more battle members are KO'd, the greater the damage
    10 = The more allies are KO'd, the greater the damage
    11 = The more it is used, the greater the damage
    12 = The more rounds have passed, the greater the damage
    13 = The greater the user's stat buffs, the greater the damage

    • int32 27: additional effect.
    Additional effect IDs

    0 = none
    3 = Nullifies unfavorable compatibility
    5 = Inverts all stat changes of the target
    6 = Steals all stat changes from the target
    7 = Recovers beyond the target's Max HP
    8 = Consumes all SP
    9 = Nullifies unfavorable attribute compatibility
    10 = Attack treated as Vaccine
    11 = Attack treated as Data
    12 = Attack treated as Virus
    13 = Attack treated as Free
    14 = Attack treated as Variable

    Icon

    • int32 32: skill icon.
      -1 = use the icon of the element set in int32 28 (no element = no icon)

    Target

    • int32 33: target.
    Target IDs

    1 = Single Enemy
    2 = Single Ally (including user)
    3 = Single Ally (excluding user)
    4 = Single Enemy or Ally
    5 = All Enemies
    6 = All Allies (including user)
    7 = All Allies (excluding user)
    8 = All Enemies or Allies
    9 = All Enemies and Allies
    10 = User
    11 = Random Enemy
    12 = Random Ally
    13 = Random Enemy or Ally

    Hits

    • int32 34: minimum hits.
    • int32 35: maximum hits.

    SP cost and other basic parameters

    • int32 36: SP cost.
    • int32 39: 0 = can miss. 1 = never misses.
    • int32 40: accuracy.
    • int32 42: critical rate.
    • int32 43: HP drain (0 to 100).
    • int32 44: SP drain (0 to 100).
    • int32 45: recoil damage (0 to 100).

    Conditions and effects

    • int32 46 and int16 49: condition.
    Condition IDs
    int32 46 (condition 1) int16 49 (condition 2)
    0 = none 0
    1 = If user is affected by stat changes, OR a buff set in "int32 52" 0
    2 = If target is affected by stat changes, OR a buff set in "int32 52" 0
    3 = If target's attribute is [#] Attribute ID
    4 = If target is weak to [#] element Element ID
    5 = If target's generation (stage) is higher than user's 0
    6 = If target's generation (stage) is lower than user's 0
    7 = If target has already acted 0
    8 = If target has yet to act 0
    9 = If target's HP is [#]% or higher HP percentage
    10 = If target's HP is [#] or lower HP percentage
    11 = If target's SP is [#]% or higher SP percentage
    12 = If target's HP is [#]% or lower SP percentage
    13 = If target's is KO'd 0
    • int32 47 and int16 50: effect.
    Effect IDs
    int32 47 (effect 1) int16 50 (effect 2)
    0 = none 0
    1 = + [#]% damage Damage percentage
    2 = Increased damage (x1.5) 0
    3 = CRT rate up by [#]% CRT percentage
    4 = (Triggers buff set in column "int32 54") 0
    5 = Recover user's HP by [#]% Restored HP percentage
    6 = Recover user's SP by [#]% Restored SP percentage
    7 = Recover user's HP/SP by [#]% Restored HP/SP percentage
    8 = Reduce target's SP by [#]% Reduced SP percentage
    • int32 52: conditional buff set. Checks whether the target is affected by a buff in buff_set.csv in order to apply an effect (for example, "extra damage if the target is affected by poison"). This field is always ignored unless the value in "int32 46" is 1 or 2.

    Buffs and Debuffs

    • int32 54: buff set 1 (Paralysis, Instant Death, ATK Down, Taunting, etc.). If "int32 47" is 4, this buff set is only applied if the conditions specified in "int32 46" are met.
    • int32 56: buff set 2.
    • int32 58: buff set 3.
    • int32 60: buff set 4.

    Form change

    • int32 61: mode change ID. Causes a temporary form change in battle. Used by Imperialdramon, Cerberusmon, etc.

    DNA Digivolution

    • int32 63: Is it a DNA Digivolution skill?: 0 = no. 1 = yes. These skills let you temporarily fuse two Digimon in combat if they are compatible, for example, Wargreymon and MetalGarurumon into Omnimon.
    • int32 64: ID of the first Digimon (only use if "int32 63" is 1, otherwise, always -1).
    • int32 65: ID of the second Digimon (only use if "int32 63" is 1, otherwise, always -1).

    003_skill_mode_change.csv

    This CSV controls temporary mode changes in combat, like when Cerberusmon turns into Cerberusmon WM after using Inferno Divide. Triggered in 000_battle_skill_list.csv int32 61.

    • int32 0: unique Mode Change ID.
    • int32 1: ID of the Digimon the user turns into.
    • int32 4: does the user return to its original form after executing the skill? 1 = no. 2 = yes.
      This only affects combat. The user always returns to its original form after combat.
    • int32 5: Controls when the user changes form:
      1 = before executing the skill.
      2 = after executing the skill (only used by MagnaGarurumon).
    • int32 6: Special Skill ID in slot 1. When a Digimon changes form, the game ignores the Special Skills set in digimon_status.mbe, so they must be assigned again here.
    • int32 8: Special Skill ID in slot 2.
    • int32 10: Special Skill ID in slot 3.
    • int32 12: Special Skill ID in slot 4.
    • int32 14 to int32 28: Special Skill IDs in slots 5 to 12. Do not use, as assigning more than four Special Skills breaks the UI.
