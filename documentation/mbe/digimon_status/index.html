    digimon_status.mbe

    This MBE contains basic digimon parameters, like traits, skills, stats and so on. It contains two CSV files: 000_digimon_status_data.csv and 001_experience_table.csv, but the latter lacks research, so we are only going to focus on the former.

    000_digimon_status_data.csv

    IDs

    • int32 0: Digimon ID.
    • string2 2: character key (a unique internal name for the Digimon). Must match the key used in char_info.mbe. Should be the Digimon name in uppercase with the char_ prefix (for example, char_AGUMON).
    • int2 3: 3D model name (without file extension).

    Stage

    • int32 4: generation/stage.
    Generation IDs

    0 = "-" (used by NPCs)
    1 = "In-Training I"
    2 = "In-Training II"
    3 = "Rookie"
    4 = "Champion"
    5 = "Ultimate"
    6 = "Mega"
    7 = "Mega +"
    8 = "Armor" (Champion stats)
    9 = "Armor" (Ultimate or Mega stats [Rapidmon and Magnamon])
    10 = "Hybrid" (Human Spirits with Champion stats [Agunimon, Lanamon and Lobomon])
    11 = "Hybrid" (Beast Spirits with Champion stats [BurningGreymon, Calmaramon and KendoGarurumon])
    12 = "Hybrid" (Fused Spirits with Ultimate stats [Aldamon and Beowolfmon])
    13 = "Hybrid" (Transcendent Spirits with Mega stats [EmperorGreymon and MagnaGarurumon])
    14 = "Cannot Train" (unused)

    Attributes

    • int32 6: attribute.
    Attribute IDs

    0 = Vaccine
    1 = Data
    2 = Virus
    3 = Free
    4 = Variable (only used by Hybrid stage Digimon)
    5 = Unknown
    6 = No Data (used by In-Training stage Digimon and some NPCs)

    About neutral attributes

    Attributes 3 through 6 are functionally identical, neither advantageous nor disadvantageous against other attributes, but have different names for lore reasons.

    Elements

    • int32 7 to int32 17: elemental resistances.
      0 = neutral
      1 = weak ⭘
      2 = double weak ⦿
      3 = resist △

    int32 8 = Fire resistance

    int32 11 = Plant resistance
    int32 12 = Wind resistance
    int32 13 = Electricity resistance
    int32 14 = Earth resistance
    int32 15 = Steel resistance
    int32 16 = Light resistance
    int32 17 = Dark resistance

    Personality

    • int32 61: base personality ID.
    Personality IDs

    0 = none (used by NPCs).

    Valor (+ ATK):

    1 = Brave (+ SP).
    2 = Zealous (+ SPD).
    3 = Daring (+ DEF).
    4 = Reckless (+ HP).

    Philanthropy (+ SPI):

    5 = Adoring (+ DEF).
    6 = Devoted (+ INT).
    7 = Tolerant (+ SP).
    8 = Overprotective (+ HP).

    Amicability (+ DEF):

    9 = Compassionate (+ HP).
    10 = Sociable (+ SP).
    11 = Friendly (+ ATK).
    12 = Opportunistic (+ SPI).

    Wisdom (+ INT):

    13 = Astute (+ SPD).
    14 = Strategic (+ SPI).
    15 = Enlightened (+ SP).
    16 = Sly (+ HP).

    Stats

    • int32 62: starting level (when converted). Default: 1.
    • int32 64: base HP (at level 1).
    • int32 65: base SP (at level 1).
    • int32 66: base ATK (at level 1).
    • int32 67: base DEF (at level 1).
    • int32 68: base INT (at level 1).
    • int32 69: base SPI (at level 1).
    • int32 70: base SPD (at level 1).
    • int32 71: growth pattern. Determines stat gains per level.
    Growth pattern IDs
    • 0 = no stat growth. Only used by NPCs.
    • 1 = high HP and ATK growth (Agumon, Guilmon, Veemon, etc.).
    • 4 = high SP and INT growth (Impmon, Lunamon, Renamon, etc.).
    • 7 = high HP, moderate ATK and SPD growth (DemiDevimon, Gabumon, Muchomon, etc.).
    • 10 = high SP, moderate INT and SPD growth (Chuumon, Funbeemon, Kudamon, etc.).
    • 13 = moderate HP, ATK and DEF growth (Hagurumon, Kamemon, Terriermon, etc.).
    • 14 = high overall stat growth from level 1 to 20, then moderate DEF, INT and SPI increase (only used by Aegiomon).
    • 16 = high SP, moderate INT and SPI growth (Betamon, Kokuwamon, Shamamon, etc.).

    Note

    For more detailed information, check the CSVs inside digimon_growth.mbe. There's a file for each growth pattern with all the stats gained from level 1 to 99, including some unused ones (5, 6, 8, 9, 11, 12 and 15).

    Skills

    Special Skills

    • int32 72: 1st Special Skill ID.
    • int32 74: voice ID used by the previous skill (should be 1).
    • int32 75: 2nd Special Skill ID.
    • int32 77: voice ID used by the previous skill (should be 2).
    • int32 78: 3rd Special Skill ID.
    • int32 80: voice ID used by the previous skill (should be 3).
    • int32 81: 4th Special Skill ID.
    • int32 83: voice ID used by the previous skill (should be 4).

    Warning: adding more than 4 Special Skills

    A Digimon can have up to 12 Special Skills, but adding more than 4 breaks the UI (weird things happen, like being unable to use Attachment Skills). Therefore, the following Special Skill columns (int32 84 to int32 107) should be ignored.

    • int32 95: voice ID used by the previous skill.
    • int32 96: 9th Special Skill ID.
    • int32 98: voice ID used by the previous skill.
    • int32 99: 10th Special Skill ID.
    • int32 101: voice ID used by the previous skill.
    • int32 102: 11th Special Skill ID.
    • int32 104: voice ID used by the previous skill.
    • int32 105: 12th Special Skill ID.
    • int32 107: voice ID used by the previous skill.
    About Special Skill voice lines

    Unlike the voice lines for other actions, which can be edited in char_info.mbe, the voice lines used for Special Skills are hardcoded and determined by the first six characters of the model name.
    For example, if you want a Digimon to use Omnimon's Special Skill voice lines, its model name must begin with chr088. It can be named chr088111, chr088923, or anything else, as long as the first six characters match Omnimon's model name.
    At the moment, it is not possible to add new Special Skill voice lines.

      They don't learn Attachment Skills.

    • In Training II:

    • Rookie:
      Skill 1: level 2.
      Skill 2: level 10.

    • Champion:
      Skill 1: level 2.
      Skill 2: level 15.
      Skill 3: level 25.

    • Ultimate:
      Skill 1: level 2.
      Skill 2: level 20.
      Skill 3: level 30.
      Skill 4: level 40.

    • Mega:
      Skill 1: level 2.

      Skill 4: level 45.

    • Mega +:
      Skill 1: level 2.
      Skill 2: level 25.
      Skill 3: level 35.
      Skill 4: level 45.

    • int32 126: unknown. Must be the same ID as the special skill in slot 1 (int32 72).

    Field Guide

    • int32 131: unique field guide ID.
      Must be a number from 477 to 999. Lower numbers are already in use, and higher numbers crash the game.
      -1 = doesn't appear in the field guide.
    • int32 132: field guide description ID from text/digimon_profile.mbe. Normally matches the ID in the first column (int32 0).
      To use the field guide description of an existing Digimon, enter its ID here.

    DLC

    • int32 133: ID of the DLC required for the Digimon to be obtainable. Only Parallelmon uses this column (29905).
