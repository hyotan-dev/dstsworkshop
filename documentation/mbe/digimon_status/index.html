    digimon_status.mbe

    This MBE contains basic digimon parameters, like traits, skills, stats and so on. It contains two CSV files: 000_digimon_status_data.csv and 001_experience_table.csv, but the latter lacks research, so we are only going to focus on the former.

    000_digimon_status_data.csv

    IDs

    • int32 0: Digimon ID.
    • string2 2: character key (a unique internal name for the Digimon). Must match the key used in char_info.mbe. Should be the Digimon name in uppercase with the char_ prefix (for example, char_AGUMON).
    • int2 3: 3D model name (without file extension).

    Stage

    • int32 4: generation/stage.
    Generation IDs

    0 = "-" (used by NPCs)
    1 = "In-Training I"
    2 = "In-Training II"
    3 = "Rookie"
    4 = "Champion"
    5 = "Ultimate"
    6 = "Mega"
    7 = "Mega +"
    8 = "Armor" (Champion stats)
    9 = "Armor" (Mega stats)
    10 = "Hybrid" (Human Spirit w/ Champion stats)
    11 = "Hybrid" (Beast Spirit w/ Champion stats)
    12 = "Hybrid" (Ultimate stats)
    13 = "Hybrid" (Mega stats)
    14 = "Cannot Train" (unused)

    Attributes

    • int32 6: attribute.
    Attribute IDs

    0 = Vaccine
    1 = Data
    2 = Virus
    3 = Free
    4 = Variable
    5 = Unknown
    6 = No Data (used by NPCs)

    Stats

    • int32 64: base HP (at level 1).
    • int32 65: base SP (at level 1).
    • int32 66: base ATK (at level 1).
    • int32 67: base DEF (at level 1).
    • int32 68: base INT (at level 1).
    • int32 69: base SPI (at level 1).
    • int32 70: base SPD (at level 1).
    • int32 71: growth pattern. Determines stat gains per level.
    Growth pattern IDs
    • 0 = no stat growth. Only used by NPCs.
    • 1 = high HP and ATK growth (Agumon, Guilmon, Veemon, etc.).
    • 4 = high SP and INT growth (Impmon, Lunamon, Renamon, etc.).
    • 7 = high HP, moderate ATK and SPD growth (DemiDevimon, Gabumon, Muchomon, etc.).
    • 10 = high SP, moderate INT and SPD growth (Chuumon, Funbeemon, Kudamon, etc.).
    • 13 = moderate HP, ATK and DEF growth (Hagurumon, Kamemon, Terriermon, etc.).
    • 14 = high overall stat growth from level 1 to 20, then moderate DEF, INT AND SPI increase (only used by Aegiomon).
    • 16 = high SP, moderate INT and SPI growth (Betamon, Kokuwamon, Shamamon, etc.).

    Note

    For more detailed information, check the CSVs inside digimon_growth.mbe. There's a file for each growth pattern with all the stats gained from level 1 to 99, including some unused ones (5, 6, 8, 9, 11, 12 and 15).

    Skills

    Special Skills

    • int32 72: first Special Skill ID.
    • int32 74: skill slot occupied by the previous skill (always 1).
    • int32 75: second Special Skill ID.
    • int32 77: skill slot occupied by the previous skill (always 2).
    • int32 78: third Special Skill ID.
    • int32 80: skill slot occupied by the previous skill (always 3).
    • int32 81: fourth Special Skill ID.
    • int32 83: skill slot occupied by the previous skill (always 4).

    Warning

    A Digimon can have up to 12 Special Skills, but adding more than 4 breaks the UI (weird things happen, like being unable to use Attachment Skills). Therefore, the following Special Skill columns (84 to 107) will be ignored and shouldn't be used.

    About Special Skill voice lines

    Unlike the voice lines for other actions, which can be edited in char_info.mbe, the voice lines for Special Skills are hardcoded. For example, Omnimon will always use the "Transcendent Sword" voice line when using the Special Skill in slot 1, even if that skill isn't actually Transcendent Sword. Therefore, if you're adding a new Special Skill to an existing Digimon, it's best to use an empty slot instead.

    Field Guide

    • int32 131: unique field guide ID. Must be a number from 477 to 999. Lower numbers are already in use, and higher numbers crash the game.
    • int32 132: field guide text ID. Same ID used in the first column (int32 0).

    DLC

    • int32 133: DLC required. Must contain the DLC flag ID. Only Parallelmon uses this column.
